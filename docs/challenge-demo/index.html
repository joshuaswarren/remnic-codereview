Guard slice(-n) against n === 0 - Pattern #27

This hunk calls `items.slice(-n)`. If `n` is zero, JavaScript returns the entire array. Add an explicit positive guard before slicing.

Incremental learning

New merged PRs become tomorrow's review memory.

The server exposes `POST /api/webhooks/github`. A GitHub `pull_request` closed event for a merged PR triggers PR-review ingestion for that one PR, so the memory store keeps growing.

  • Ignores unmerged or unsupported events
  • Fetches the merged PR review surfaces
  • Stores new lessons in the configured memory dir

Why this is not just a prompt

Prompts do not keep a durable lesson ledger, remember source provenance, incrementally learn from merged PRs, or attach line-level GitHub comments after a retrieval and judgment pipeline. This is a memory system wrapped around a practical developer workflow.
